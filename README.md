# bridge40：40 m 簡支後拉預力 I 型梁橋設計程式

繁體中文 | [English](README.en.md)

依交通部「公路橋梁設計規範」（98 年版，含 104、109 年修訂）與「公路橋梁耐震設計規範」（107 年 12 月版），計算一座 40 m 簡支後拉預力 I 型梁橋的上部結構，並由計算結果直接產生三張 A3 設計圖。

> 這是方法示範，不是可施工的設計。橋台、基礎與液化沒有設計；實際設計須由執業技師負責並簽證。

![S-01 一般配置圖](out/S-01.png)

完整的設計說明（載重、預力、應力、強度、剪力、錨碇區、橋面版、支承、耐震）在 [docs/design-notes.md](docs/design-notes.md)。

## 設計條件

| 項目 | 採用值 |
| --- | --- |
| 橋型 | 單跨簡支，支承中心距 40 m，梁長 40.8 m |
| 橋面 | 寬 9.0 m（兩車道），版厚 200 mm |
| 主梁 | 4 支後拉預力 I 型梁，梁距 2.4 m，梁高 2.1 m，橋址附近預鑄 |
| 預力 | 每支梁 4 束拋物線鋼腱，每束 10 股 15.2 mm 低鬆弛鋼絞線 |
| 活載重 | HS20-44 |
| 混凝土 | 梁 f'c 35 MPa（施預力時 28 MPa），橋面版 28 MPa |
| 橋址 | 台中市南屯區，近斷層範圍；地盤假設第二類（Vs30 = 180 m/s） |

## 主要結果

| 檢核 | 計算值 | 容許值 | 比值 |
| --- | --- | --- | --- |
| 撓曲強度 Mu / φMn | 15,686 kN·m | 19,894 kN·m | 0.79 |
| 施預力時梁底壓應力（毛斷面） | −14.48 MPa | 0.55 f'ci = −15.40 MPa | 0.94（扣除套管後超過，見下方「獨立核對」） |
| 使用載重梁底拉應力 | +1.73 MPa | 0.498√f'c = 2.95 MPa | 0.59 |
| 活載重加衝擊撓度 | 10.8 mm | L/800 = 50 mm | 0.22 |
| 剪力 Vu / φVn（全梁最大） | — | — | 0.68 |
| 支承墊平均壓應力 | 6.51 MPa | 6.86 MPa | 0.95 |

耐震：等級 II 工址短週期譜加速度 0.92 g。只靠橡膠支承墊會位移 236 mm，因此設止震塊（每座橋台橫向 3,133 kN）；防落長度採 80 cm（規範最小 60 cm）；每個支承需抗拉拔裝置，極限承載力 ≥ 128 kN。

## 執行

```bash
pip install -r requirements.txt
python run_all.py              # 計算與出圖，結果輸出到 out/
python docs/make_figures.py    # （選用）重畫設計說明的兩張圖，需要 matplotlib
python checks/hand_checks.py   # 產生獨立核對計算書 checks/hand_checks.md
```

需要 Python 3.10 以上。出圖用 cairosvg，系統需有「Noto Sans CJK TC」字型（Debian/Ubuntu：`apt install fonts-noto-cjk`）。

要改跨徑、梁距、鋼腱位置或橋址係數，改 `bridge40/params.py` 再執行一次 `python run_all.py`，計算書與三張圖的尺寸、數字會一起更新；部分標註位置可能需要微調。

## 程式結構

| 模組 | 做什麼 |
| --- | --- |
| `bridge40/params.py` | 所有輸入：幾何、材料、鋼腱、載重、橋址與地震參數。改這裡，計算與圖面一起改 |
| `bridge40/section.py` | 斷面性質（多邊形公式，另以拆塊手算與薄條積分核對）、有效翼寬、合成斷面 |
| `bridge40/analysis.py` | OpenSeesPy 800 元素簡支梁；單位載重影響線矩陣；HS20-44 與車道載重包絡；影響線解析解與閉合解核對 |
| `bridge40/design.py` | 輪重分擔、呆載重、鋼腱線形、摩擦與錨碇滑動、預力損失、施工與使用應力、強度、撓度與預拱、剪力（Vci／Vcw）、水平剪力、錨碇區、橋面版、支承墊、耐震 |
| `bridge40/report.py` | 整理結果、輸出 JSON 與計算摘要 |
| `bridge40/drawings.py` | 由參數與結果產生 SVG 圖面 |
| `bridge40/page.py` | 把圖面組成網頁 |
| `docs/make_figures.py` | 由 `results.json` 畫設計說明裡的鋼腱應力圖與反應譜圖 |
| `checks/hand_checks.py` | 獨立核對計算書產生器：只讀 `params.py`，不呼叫主程式，逐行重算並與結果對照 |

## 主要假設（條文沒有規定、由本程式自行選定）

- 鋼腱側向 S 形彎轉每處 0.10 rad；錨碇滑動 6 mm；摩擦 K = 0.0007/m、μ = 0.25（表 8.1 範圍上限）。
- 梁端剪力分配係數由槓桿法 1.75 線性過渡到 L/4 處的 S/1.65。
- 欄杆載重乘活載重係數 1.3 × 1.67。
- 止震塊設計力取等級 II 反應譜平台值（下部結構週期未知）；縱向由一座橋台承受。
- 拉拔檢核用彈性水平力，未折減。
- 地盤以第二類、Vs30 = 180 m/s 計算（無地質資料）。
- 架設後乾縮潛變縮短 0.0004 L；線膨脹係數 10.8 × 10⁻⁶/°C。

## 限制

橋台、基礎、液化與背填土地震土壓力未設計，需要鑽探資料；止震塊與抗拉拔裝置只算到設計力，沒有細部；上拱與下垂的長期潛變、吊裝與運輸階段未檢核；錨碇區局部承壓需採用廠商試驗合格的特殊錨碇裝置。

## 獨立核對

[checks/hand_checks.md](checks/hand_checks.md) 把預力損失、跨中梁底應力、φMn、Vcw、爆裂力、支承墊與止震塊逐行寫出公式、條號、代入的數字與結果，並與程式結果對照，供結構技師逐行檢查。它由 `checks/hand_checks.py` 產生，只讀輸入參數，斷面、彎矩、摩擦等都用和主程式不同的方法重算。它和主程式一樣由 AI 撰寫，**尚未經人工複核**。

核對發現的主要問題：依〔設〕8.17.1，後拉構材灌漿前的斷面應扣除套管開孔。扣除後施預力時梁底壓應力約 −15.7 MPa，超過 0.55 f'ci = −15.4 MPa。主程式目前用毛斷面計算，這一項需要修改（例如施預力時 f'ci 提高到 30 MPa）。其餘需要技師判斷的事項見計算書第 14 節。
